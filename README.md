## 🎬 1분호기심 — 유튜브 완전 자동화 (개인 · 운영 중)

심리학·뇌과학·행동경제학으로 일상을 풀어내는 지식 쇼츠 채널입니다. 기획·개발·운영을 혼자 맡고 있습니다.
→ [채널 보기](https://www.youtube.com/channel/UCQVL7FSlbK2p6AWxx9EfdUA)

```mermaid
flowchart LR
    A[트렌드 수집] --> B[전략 엔진<br/>오늘 주제 결정]
    B --> C[AI 대본<br/>+ 검수 에이전트]
    C --> D[내레이션·자막·영상<br/>렌더링]
    D --> E[유튜브 업로드]
    E --> F[매일 밤<br/>성과 기록]
    F --> G[일요일 회고<br/>전략 갱신]
    G --> B
```

| 숫자 (2026-11-09 기준) | |
|---|---|
| 하루 발행 | **2편** (아침 7시 · 저녁 6시) · 사람 개입 0 |
| 공개 영상 | **205편** (쇼츠 197 · 롱폼 8) |
| 총 조회수 | **138,337회** · 구독자 106명 |
| 정책 위반 · 플랫폼 제재 | **0건** |
| 외부 생성 API 비용 | **0원** (로컬 GPU) |

- 주제 반복·제목 규칙·의료 단어를 **코드로 강제**해 LLM 출력이 흔들리지 않게 함
- 생성 에이전트와 검수 에이전트를 나눠, 만든 쪽이 자기 결과물을 스스로 통과시키지 못하게 구성
- 일요일 회고 에이전트가 직전 전략을 스스로 채점하고, 성과 없는 전략은 ROI 0으로 판정해 중단
- 지난 쇼츠를 묶어 **8분 이상 몰아보기 롱폼**을 자동으로 만들고 수·토 저녁에 예약 공개 (2026-11~)
- 실패하면 폰 푸시 알림, 올린 영상이 사라지면 한 번 알림

## 💄 nudy — 팀 1단2조 (완료)

한 부위씩 잡아주는 **화장 코치** 서비스입니다. 맨얼굴을 촬영하고, 룩을 얹어 본 뒤, 부위별로 그릴 자리를 보며 화장하고 점수를 받습니다.
→ [1DAN-2ZO/support-yr-makeup](https://github.com/1DAN-2ZO/support-yr-makeup)

제가 맡은 부분

- **첫 화면 촬영 기능** — MediaPipe로 얼굴을 인식해 촬영 화면을 구성하고, 촬영 이미지를 다음 단계로 전달

- **이미지 생성 서버 구성** — FLUX를 팀의 RTX 3060 서버에 올려 외부 생성 API 없이 동작
- **서비스 마케팅 단독 담당** — 마케팅 영상 14편을 **ComfyUI**로 제작하고 인스타·쓰레드·유튜브 3개 채널을 직접 개설·운영 ([youtube.com/@nudy.makeup](https://www.youtube.com/@nudy.makeup)), 매일 시장 조사를 대시보드와 인사이트로 정리

## 🏠 집가 (ZipGa) — 팀 1단2조 (완료)

링크·QR로 모여 미니게임을 하고, 점수가 낮으면 "집 가" 하고 카카오T가 뜨는 웹앱입니다. → [사이트](https://zip-ga-frontend.vercel.app/)
6인 팀에서 **마케팅 자동화를 단독으로** 맡아, 영상 생성부터 5개 채널 발행까지 하나의 파이프라인으로 만들었습니다.

```mermaid
flowchart LR
    A[영상 투입] --> B[정규화] --> C[전사] --> D["9:16 클립"] --> E[채널별 문구] --> F[유입 링크] --> G[발행 큐]
    G --> H1[유튜브]
    G --> H2[인스타]
    G --> H3[쓰레드]
    G --> H4[네이버블로그]
    G --> H5[티스토리]
```

- API가 연결되지 않은 채널은 **보조 모드로 자동 강등**(페이지 열기·문구 복사)해 한 채널 때문에 전체가 멈추지 않게 설계
- ComfyUI를 자동으로 띄워 로컬 GPU로 영상·BGM 생성 → 외부 생성 API 비용 0원
- 제재 예방 규칙(금지 표현·장면)을 정해 기획·프롬프트·해시태그를 일괄 교체 → 제재 0건

## 🍽 냠냠플래닛 (YummyPlanet) — 팀 프로젝트 (완료)

신체 정보와 목표를 넣으면 AI가 하루 식단을 짜고, 웹캠으로 운동 자세를 분석하는 웹 서비스입니다. React + Spring Boot(MyBatis · MySQL) + FastAPI.
**→ [jeakeun/project](https://github.com/jeakeun/project)** (제가 맡은 부분을 README에 정리해 두었습니다) · 팀 원본 [YH-KIKI/YummyPlanet](https://github.com/YH-KIKI/YummyPlanet)

- **AI 식단 추천**: KNN이 칼로리 수치만 맞춰 조리되지 않은 재료를 추천하던 문제를,
  분류명 기반 카테고리 필터링과 목표 칼로리에 맞춘 섭취량(g) 자동 분배로 해결 → 밥·국·메인·반찬이 갖춰진 한 끼
- **실시간 자세 분석**: MediaPipe로 웹캠 관절 좌표를 추출하고, 프레임 단위 상태 관리를 최적화해 렌더링 지연 없이 피드백
- **API 연동**: Axios로 RESTful API 3개를 설계·연동해 프론트–백엔드 통신 구조 구축
